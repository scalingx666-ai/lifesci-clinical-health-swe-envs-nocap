## Proposed Changes

The CARE PR Reviewer (gh-aw) workflow failed with `spawn /usr/local/bin/copilot ENOENT` — the copilot engine terminated before producing output because the CLI binary was never installed.

Root cause: `care-review.lock.yml` was generated by a stale gh-aw compiler (v0.84.3 / copilot 1.0.77), whose `gh-aw-actions/setup` step no longer places the copilot binary at `/usr/local/bin/copilot`. Other workflows in the repo (e.g. grumpy-reviewer) were already on a newer compiler.

- Recompiled `care-review.md` via `gh aw compile care-review`, regenerating `care-review.lock.yml` to compiler v0.86.2 / copilot 1.0.79 with the corrected install step
- Bumped the `gh-aw-actions/setup` pin to v0.86.2 in `.github/aw/actions-lock.json`
- Source `care-review.md` is unchanged (frontmatter/body hashes identical); only generated artifacts changed
