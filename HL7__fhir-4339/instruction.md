## Status binding: FHIR-59543

The status part of FHIR-57813 ("a new value set that is the combination of PublicationStatus and MedicationStatus") is replaced by [FHIR-59543](https://jira.hl7.org/browse/FHIR-59543) (Persuasive). That combination reduces to PublicationStatus: `active` is the same concept in both code systems, `inactive` corresponds to `retired`, and `entered-in-error` is `retired` for canonical resources. Commit c95acb038a:

- `Medication.status`:
  - required common binding to `http://hl7.org/fhir/ValueSet/publication-status`, as for other canonical resources;
  - short "draft | active | retired | unknown", with a new definition, comment and modifier reason.
- Build entered-in-error convention: `.status = retired`.
- `status-codes.xml`: the Medication.status row is draft, active, retired, unknown.
- Removed:
  - `codesystem-medication-status.xml` and `valueset-medication-status.xml` (Medication);
  - a stale duplicate `valueset-medication-status.xml` in `medicationadministration/`.

  The OIDs stay registered.
- R5 → R6: `inactive` and `entered-in-error` become `retired`, and `active` is unchanged. This is recorded in the release note; the conversion maps are maintained outside this repository.

## Normative note

Medication is normative. The canonical elements are additive (all optional). The status binding change (FHIR-59543) is a breaking change from R5 for `Medication.status`: `inactive` and `entered-in-error` map to `retired`. It was voted by the WG.
