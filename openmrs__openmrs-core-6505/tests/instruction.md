The ticket asks for caching the compiled patterns and the enabled flag, both of which are set through Global Properties. In addition, this implements some more optimizations, e.g., using ConfigUtil's cache for GPs and two semantic-preserving changes to UserContext which completely removes an allocation in the (common) case where there is only one privilege added per `addProxyPrivilege` call.

The GZIPFilterTest class is moved to the right package and regression tests for caching are added.
